# Chạy game trên MacBook (macOS)

Yêu cầu: Người Lười Tu Tiên chạy được trên MacBook (Apple Silicon trước, Intel sau), giữ nguyên bản Windows.

## Hiện trạng

- **Đã đa nền tảng**: server ASP.NET Core 8 (`Program.cs` phần `BuildServer`/`MapApi`), toàn bộ `Game/`, `Data/` (EF Core + SQLite, SQLitePCLRaw có sẵn native `osx-arm64`/`osx-x64`), giao diện `wwwroot/` (HTML + canvas). Không có `DllImport`/WinForms trong `Game/` và `Data/`.
- **Chỉ chạy Windows**:
  - `VanDao.csproj`: `net8.0-windows`, `UseWindowsForms`, gói `Microsoft.Web.WebView2`, icon `.ico`.
  - `Program.Main`: gọi `Application.Run(new GameWindow(url))` (WinForms).
  - `Desktop/GameWindow.cs`, `PanelWindow.cs`, `WebHost.cs`, `Theme.cs`, `WindowSettings.cs`: WinForms + WebView2, neo dải trên taskbar, khay hệ thống.
  - `Desktop/Native.cs`: `user32.dll` (hotkey Shift+F11/F12, kéo cửa sổ), `dwmapi.dll`.
  - `NguoiLuoiTuTienLauncher/`: WinForms, cập nhật bằng zip + script ghi đè exe.
  - CI `build-release.yml`: chỉ `windows-latest`, `-r win-x64`.
- **Cầu nối JS ↔ cửa sổ**: `window.chrome.webview.postMessage({type})` trong `wwwroot/js/core.js:13` và `main.js:17,275-277`. Các tin: `drag`, `menu`, `open-panel`, `changed`, `shape`, `close-panel`, `tab`, `break`. Chiều ngược lại C# gọi `ExecuteScriptAsync("window.sync()/openTab()/playBreak()/redeemCode()/setOpaque()")`.
- `AppPaths.DataDir` dùng `SpecialFolder.LocalApplicationData`. Trên macOS với .NET 8 là `~/Library/Application Support/VanDao`, dùng được luôn.

## Thiết kế

Giữ một project game, **đa target**: `net8.0-windows` (như cũ) và `net8.0` (macOS/Linux). Lớp cửa sổ desktop là phần duy nhất tách theo nền tảng.

- **Bản Mac dùng Photino.NET** (cửa sổ native dùng WKWebView, nhẹ, NuGet thuần .NET), không dùng Electron/Avalonia. Phương án dự phòng nếu Photino không làm được cửa sổ không viền/luôn nổi: mở trình duyệt mặc định ở chế độ `--web` (đã chạy được hôm nay).
- **Cầu nối JS trung lập**: thay các chỗ gọi `window.chrome.webview` bằng một hàm `hostPost(msg)` / cờ `HAS_HOST` trong `core.js`: dùng `chrome.webview.postMessage` nếu có, nếu không thì `window.external.sendMessage(JSON.stringify(msg))` (Photino). Không đổi tên tin nhắn để C# hai bên dùng chung một bộ xử lý.
- **Trải nghiệm trên Mac** (macOS không có taskbar kiểu Windows):
  - Dải 280×200 thành cửa sổ không viền, luôn nổi, mặc định neo góc dưới phải phía trên Dock. Kéo bằng tin `drag`.
  - Menu chuột phải / nút bánh răng: menu HTML trong trang (Photino không có context menu native), gồm kích thước, ghim, đặt lại vị trí, thoát.
  - Bỏ khay hệ thống và hotkey toàn cục ở bản đầu. Đặt lại vị trí/kích thước nằm trong menu. Cmd+Q thoát.
  - Cửa sổ Tu luyện (`mode=panel`) là cửa sổ Photino thứ hai có viền.
- **Dữ liệu**: `~/Library/Application Support/VanDao/vandao.db` + `window.json`. Save không tự sang từ máy Windows. Sau này có thể thêm nút xuất/nhập file `.db`.
- **Cập nhật**: không port Launcher. `VersionService` (bảng `app_config` trên Supabase) đã có `download_url`. Thêm cột/nhánh theo nền tảng (`download_url_mac`) để màn hình cập nhật trong game mở trang release cho bản Mac.
- **Đóng gói**: `.app` bundle (`Contents/MacOS/NguoiLuoiTuTien` + `wwwroot`, `Contents/Info.plist`, `Contents/Resources/icon.icns`), nén `.zip` (sau này `.dmg`). `ContentRootPath = AppContext.BaseDirectory` vẫn đúng vì `wwwroot` nằm cạnh file chạy trong `Contents/MacOS`.
- **Ký và notarize**: cần Apple Developer ($99/năm). Chưa có thì phát hành không ký và hướng dẫn người chơi chuột phải → Open, hoặc chạy `xattr -dr com.apple.quarantine NguoiLuoiTuTien.app`.

## Các bước

### Giai đoạn 0: Chơi được ngay (không đổi code Windows)
- [ ] Tách build: `TargetFrameworks` = `net8.0-windows;net8.0`. Trên `net8.0`: tắt `UseWindowsForms`, bỏ gói WebView2, bỏ `Desktop/**` trừ `AppPaths.cs`, bỏ `ApplicationIcon`/`OutputType WinExe`.
- [ ] `Program.Main`: bọc phần WinForms trong `#if WINDOWS`. Nhánh còn lại chạy server ở `127.0.0.1:0` rồi mở trình duyệt mặc định (`open <url>`), hoặc chạy `--web`.
- [ ] Kiểm tra `tools/manual_checks` và `tools/pet_cadence_checks` có target `net8.0` để chạy trên Mac.
- [ ] Kiểm tra trên Windows: `dotnet build -f net8.0` và `dotnet run -f net8.0 -- --web` chạy được. `dotnet build -f net8.0-windows` không đổi hành vi.
- [ ] Kiểm tra trên Mac thật: `dotnet run -f net8.0 -- --web`, chơi trong Safari và Chrome: tạo nhân vật, chiến đấu, hiệu ứng skill (`fire-fx.js`, WebP), lưu/tải lại, bảng xếp hạng, chợ.

### Giai đoạn 1: Cửa sổ game native trên Mac
- [ ] Thêm `hostPost`/`HAS_HOST` vào `core.js`, thay 4 chỗ dùng `window.chrome.webview` trong `core.js`/`main.js`. Kiểm tra lại bản Windows (WebView2) không đổi.
- [ ] Spike Photino (1 ngày): cửa sổ không viền + luôn nổi + nền trong suốt + kéo + DPI Retina (`devicePixelRatio = 2` trong `reportShape`). Không đạt thì dừng ở giai đoạn 0 (trình duyệt).
- [ ] `DesktopMac/MacGameWindow.cs` (chỉ biên dịch cho `net8.0`): dải game, xử lý `drag`/`menu`/`open-panel`/`changed`/`shape`, lưu vị trí bằng `WindowSettings` (tách phần không phụ thuộc WinForms ra dùng chung).
- [ ] `DesktopMac/MacPanelWindow.cs`: cửa sổ Tu luyện, xử lý `close-panel`/`tab`/`break`, đồng bộ hai chiều qua `window.sync()`.
- [ ] Menu cài đặt bằng HTML khi chạy trong Photino (nhập code quà, kích thước 75–200%, ghim, đặt lại vị trí, thoát).

### Giai đoạn 2: Đóng gói và phát hành
- [ ] Script `tools/package-macos.sh`: `dotnet publish -f net8.0 -r osx-arm64 --self-contained -p:PublishSingleFile=true`, dựng `.app`, tạo `icon.icns` từ ảnh trong `wwwroot/img/app/`, `chmod +x`, nén zip.
- [ ] CI: thêm job `macos-latest` trong `build-release.yml` để publish `osx-arm64` (và `osx-x64` nếu cần), đính kèm `VanDao_vX.Y.Z_macos-arm64.zip` vào cùng GitHub Release. Launcher Windows đang chọn asset `.zip` không chứa "Launcher", nên phải đổi bộ chọn đó để không tải nhầm zip Mac.
- [ ] `app_config`: thêm link tải cho Mac; `VersionService` chọn link theo `OperatingSystem.IsMacOS()`.
- [ ] (Khi có tài khoản Apple Developer) `codesign --options runtime` + `notarytool` + `stapler` trong CI, secrets lưu ở environment `Supbase`.
- [ ] README: mục "Chạy trên macOS" (yêu cầu, vị trí save, cách mở bản chưa ký).

## Rủi ro

- Không có Mac trong máy dev hiện tại: giai đoạn 0 kiểm tra build trên Windows được, còn chạy thật và giao diện WKWebView/Safari thì cần Mac.
- WKWebView khác Chromium: `backdrop-filter`, font, `image-rendering: pixelated`, WebP động, `localStorage` dùng chung giữa hai cửa sổ (WebView2 đang chia sẻ qua cùng một thư mục profile; Photino cần kiểm tra).
- Photino có thể thiếu nền trong suốt hoặc cửa sổ không viền tùy phiên bản. Nếu vậy thì dùng phương án trình duyệt.
- Build release phải chỉ rõ `-f` khi đã đa target, nếu không `dotnet publish` báo lỗi. Cập nhật lệnh trong `build-release.yml` và `NguoiLuoiTuTienLauncher/package_game_release.ps1`.

Không đổi luật chơi, chỉ số hay cấu trúc save. Giữ nguyên các thay đổi đang có trong workspace (nhánh `codex/four-elements`).
